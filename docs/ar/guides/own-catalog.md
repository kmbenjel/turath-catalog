# فهرسك أنت في الجداول نفسها

الأداة لا تخص مكتبة واحدة. أعطها ملف CSV فيه سطر لكل طبعة، فتخرج لك الجداول الثمانية نفسها، بالمعرّفات
نفسها، وتفحصها، وتربط كتبك بـ OpenITI ومؤلفيك بويكي بيانات.

## الملف

الحقل الوحيد الإلزامي `title`. وهذه الحقول المقروءة:

| الحقل | معناه | مثال |
|---|---|---|
| `title` | عنوان الكتاب | الرسالة |
| `author` | اسم المؤلف المشهور | الشافعي |
| `author_death_ah` | سنة الوفاة بالهجري | 204 |
| `category` | أحد أقسام الشاملة الأربعين (وغيره يوضع في «كتب عامة») | أصول الفقه |
| `editors` | المحققون مفصولين بـ `;`، ويجوز ذكر الدور قبل الاسم | `editor:أحمد محمد شاكر` |
| `publisher` و`place` | الناشر والمكان | مصطفى البابي الحلبي، القاهرة |
| `year_ah` و`year_ce` | سنة الطبع | 1358، 1940 |
| `edition_number`، `volumes`، `pages` | رقم الطبعة وعدد المجلدات والصفحات | 1، 1، 600 |
| `kind` | `printed` أو `lithograph` أو `manuscript` أو `thesis` أو `offprint` | printed |
| `work` | مفتاح تجمع به طبعات الكتاب الواحد إن اختلفت عناوينها | risala |
| `sizes` | أحجام الملفات بالبايت مفصولة بـ `;` | 1000;2000 |
| `verified` | `yes` إن قرأت صفحة العنوان بنفسك | yes |

## البناء

```bash
turath-catalog build --csv my-library.csv --out my-release
```

```bash
turath-catalog validate my-release
```

```bash
turath-catalog info my-release
```

!!! note "ملاحظة"
    في المرة الأولى تنزّل الأداة بيانات OpenITI (نحو 12 ميغابايت) ونتائج ثلاثة استعلامات صغيرة من ويكي بيانات، وتحفظها في مجلد `cache`. وللعمل دون اتصال أضف `--offline`.

## ثم ماذا؟

- اعرض الجداول فهرسًا يُتصفح على الهاتف بأداة [pocketshelf](/pocketshelf/) من ملف `pocketshelf.csv`.
- قابل فهرسك بالشاملة والوقفية وarchive.org بأداة [turath-match](/turath-match/).
